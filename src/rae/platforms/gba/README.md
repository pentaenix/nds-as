# GBA platform (planned)

Retro Asset Extractor will add Game Boy Advance support here:

- ROM layout and cartridge headers
- LZ77 compression (and per-game variants)
- Tile maps, tilesets, palettes, OAM sprites
- Room/map bundles wired through `mappings/gba/`

Contributions welcome via PR to community mapping files under `mappings/gba/`.
